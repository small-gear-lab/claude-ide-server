# claude-ide-server

An unofficial IDE integration server for Claude Code's `/ide` protocol.

**Status: early development. The core library talks to a real Claude Code and is tested with stand-ins; the server runs as an executable; the Neovim adapter connects, registers and sends the selection, and does not yet answer Claude Code's requests.**
